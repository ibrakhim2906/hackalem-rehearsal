# Quiz Mentor

## Краткое описание

Quiz Mentor помогает школьнику быстро закрепить тему: создаёт три вопроса на казахском, русском или английском языке, проверяет один ответ и объясняет результат. Это минимальный сценарий персональной практики без хранения персональных данных.

## Что реализовано

- Ввод темы и выбор языка `kk`, `ru` или `en`.
- Генерация ровно трёх вопросов с четырьмя вариантами через OpenAI function calling.
- Проверка ответа на первый вопрос и объяснение правильного ответа.
- Журнал шагов агента в интерфейсе.
- Понятные сообщения при пустом/длинном вводе, неверном языке, отсутствии ключа или ошибке API.

## Как работает решение

1. Ученик вводит тему и язык.
2. Агент планирует запрос и вызывает функцию `publish_quiz` через OpenAI.
3. Код проверяет структуру трёх вопросов и показывает их в Streamlit.
4. Ученик выбирает вариант первого вопроса; функция `grade_answer` детерминированно оценивает его и возвращает объяснение.

### Соответствие требованиям кейса

| Требование | Как выполнено | Где в коде | Как проверить |
|---|---|---|---|
| Тема и три языка | Поле темы и выбор `kk/ru/en` | `app.py`, `agent/core.py` | Выбрать язык и создать квиз |
| Три вопроса через OpenAI tools | Модель принудительно вызывает `publish_quiz` | `agent/core.py`, `agent/tools.py` | Запустить с ключом |
| Проверка ответа с объяснением | Сверка варианта и объяснение | `agent/tools.py` | Ответить на первый вопрос |
| Видимые шаги агента | План, инструмент и проверка выводятся в UI | `app.py` | Открыть «Шаги агента» |

### Как работает AI-агент

Промпт хранится в `agent/prompts.py`. В `agent/core.py` агент валидирует вход, просит модель вызвать JSON-инструмент `publish_quiz`, затем инструмент валидирует структуру. После выбора ученика `grade_answer` выполняет воспроизводимую проверку. UI получает и показывает краткий журнал всех шагов.

## Технологии

Python 3.11+, Streamlit 1.49.1, OpenAI Python SDK 1.109.1, python-dotenv 1.1.1 и pytest 8.4.2. Модель задаётся переменной `OPENAI_MODEL` (по умолчанию `gpt-4.1-mini`). Внешняя интеграция — OpenAI API.

## Архитектура проекта

```text
app.py (Streamlit UI)
  -> agent/core.py (цикл OpenAI tool calling, валидация, журнал)
       -> agent/prompts.py (системный промпт)
       -> agent/tools.py (publish_quiz и grade_answer)
  -> OpenAI API
```

## Установка и запуск

Требуется Python 3.11+ и ключ OpenAI API для генерации вопросов.

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
# Откройте .env и укажите OPENAI_API_KEY
python -m streamlit run app.py
```

Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
# Добавьте OPENAI_API_KEY в .env
python -m streamlit run app.py
```

| Переменная | Назначение | Пример | Обязательна |
|---|---|---|---|
| `OPENAI_API_KEY` | Ключ доступа к OpenAI API | `sk-...` | Да, для генерации |
| `OPENAI_MODEL` | Имя модели | `gpt-4.1-mini` | Нет |

## Как проверить решение

Введите тему `фотосинтез`, выберите `ru`, нажмите «Создать квиз», выберите ответ на первый вопрос и нажмите «Проверить ответ». Должны появиться три вопроса, результат, объяснение и журнал шагов. Пример хранится в `data/sample_input.txt`.

Запуск тестов:

```powershell
python -m pytest -q
```

### Обработка ошибок и безопасность

Пустая и слишком длинная тема, неправильный язык и неверный номер ответа обрабатываются дружелюбными сообщениями. При отсутствии `OPENAI_API_KEY` приложение запускается и сообщает, как настроить ключ; готовые вопросы не подменяются. Ключи находятся только в `.env`, который исключён из Git.

### Тесты

Два pytest-теста подменяют вызов OpenAI: проверяют обработку tool call и дружелюбную обработку неверного ввода/оценивание ответа.

## Данные и интеграции

`data/sample_input.txt` — вымышленный пример сценария, `data/seed_data.json` — обезличенный профиль и темы для демонстрации. Вопросы создаёт OpenAI API в реальном времени; приложение не сохраняет ответы ученика.

## Ограничения

Проверяется только первый вопрос из квиза. Нужен действующий ключ OpenAI API и доступ к сети; нет авторизации, постоянного хранения прогресса и режима без API.
